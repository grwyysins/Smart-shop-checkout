# Smart Shop Checkout System
## Description
The Smart Shop Checkout System is a Python terminal-based
checkout program designed for a small retail shop.

The system allows customers to:

- View available products
- Select products using product codes
- Enter quantities
- Add multiple products to a basket
- View their current basket
- Remove products
- Calculate the basket subtotal
- Receive discounts
- Make payments
- Calculate change
- Receive a final receipt

## Technologies Used
- Python
- Dictionaries
- Functions
- Loops
- Conditional statements
- Input validation

## Discount System
The program provides two discount levels:

- KSh 5,000 or more → 5% discount
- KSh 10,000 or more → 10% discount
